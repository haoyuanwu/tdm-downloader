连接 Safari 与 TDM

在 Safari 扩展设置中启用「TDM 下载助手」，再允许访问需要下载的网站。

扩展已启用。允许访问下载网站并刷新网页，即可点击文件链接或使用右键菜单交给 TDM 下载。

扩展尚未启用。打开 Safari 扩展设置，勾选「TDM 下载助手」。

扩展列表里没有「TDM 下载助手」？
  1. 在 Safari → 设置 → 高级中开启「显示网页开发者功能」（旧版为「在菜单栏中显示开发菜单」）。
  2. 在 Safari「开发」菜单或开发者设置中手动允许未签名的扩展。
  3. 返回 Safari → 设置 → 扩展，启用 TDM 下载助手，并允许所需网站。
  4. 返回本安装器点击「重新检查」。重启 Safari 后可能需要重新允许未签名扩展。

临时签名试用版：若扩展没有出现，请在 Safari 的「开发」菜单中允许未签名的扩展。完整教程见 TDM → 设置 → 浏览器扩展。
